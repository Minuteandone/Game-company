Run locally

A little server, a whole arcade.

Download or clone the public repository. From its root folder, start a local static HTTP server. Open the address below to browse all four prototypes. A local server is important because two experiments use JavaScript modules.

python3 -m http.server 8000

Then visit http://localhost:8000/

A modern desktop or mobile browser is recommended. No sign-in, paid service, or build step is required to play.
